# AlienByNature system

Калькулятор гармонии лица: гармония, угловатость, диморфизм, misc, общий балл, SMV, краниальная база, шкала градаций и источники.

Один файл `index.html`, без сборки и зависимостей (шрифты подгружаются с Google Fonts). Данные сохраняются в браузере.

## Запуск
Открой `index.html` в браузере.

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub и загрузи все файлы из этой папки.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Сайт появится по адресу `https://<ник>.github.io/<репозиторий>/`.

Либо выбери Source: **GitHub Actions**, и деплой пойдёт автоматически из `.github/workflows/pages.yml`.
